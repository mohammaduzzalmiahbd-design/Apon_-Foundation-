গুগল ব্লগারে যুক্ত করার নিয়ম

আপনার "আপন ফাউন্ডেশন ম্যানেজমেন্ট সিস্টেম" সফটওয়্যারটি গুগলের ব্লগারে (Blogger) যুক্ত করার জন্য নিচের ধাপগুলো অনুসরণ করুন।

ধাপ ১: কোড হোস্ট করা

ব্লগার সরাসরি রিয়েক্ট অ্যাপ (React App) চালাতে পারে না। তাই প্রথমে এই অ্যাপটি একটি ফ্রি হোস্টিংয়ে আপলোড করতে হবে।

  • Netlify Drop এ যান।
  • আপনার প্রোজেক্টের dist ফোল্ডারটি সেখানে ড্র্যাগ করে ছেড়ে দিন। (প্রথমে npm run build কমান্ড দিয়ে বিল্ড করে নিতে হবে)।
  • আপলোড হলে তারা আপনাকে একটি লিংক দেবে (যেমন: https://apon-foundation-app.netlify.app)।
ধাপ ২: ব্লগারে পেজ তৈরি
  • আপনার ব্লগারের ড্যাশবোর্ডে লগইন করুন।
  • বাম পাশের মেনু থেকে Pages এ ক্লিক করুন এবং New Page এ ক্লিক করুন।
  • পেজের টাইটেল দিন (যেমন: "সদস্য তালিকা ও গঠনতন্ত্র")।
ধাপ ৩: কোড পেস্ট করা

এবার এডিটরের বাম পাশে পেন্সিল আইকনে ক্লিক করে HTML View সিলেক্ট করুন। আগে থেকে কিছু থাকলে মুছে ফেলুন এবং নিচের কোডটি পেস্ট করুন:

নোট: "আপনার_অ্যাপের_লিংক_এখানে_দিন" এর জায়গায় ধাপ ১ এ পাওয়া লিংকটি বসান।

ধাপ ৪: সেভ ও পাবলিশ

সবশেষে ডানদিকের উপরে Publish বাটনে ক্লিক করুন। এখন আপনার ব্লগের মেনুতে এই পেজটি যুক্ত করে দিন।

টিপস: অ্যাপের ভেতরে "ডাটা ও সেটিংস" অপশনে গেলে আপনি অটোমেটিক কোড জেনারেটর পাবেন।
